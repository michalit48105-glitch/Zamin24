# חיבור Google Sheets — משימות הכנה

מטרה: גיליון אחד שאליו נאספות כל הפניות — גם מטופס האתר וגם מהבוט.
כל המשימות כאן הן דברים שרק אתה יכול לעשות (חשבונות, הרשאות). את חיבור הקוד אני אעשה בפגישה הבאה.

---

## משימה 1: יצירת הגיליון (5 דקות)

1. היכנס ל-https://sheets.google.com עם החשבon michael.hamo29@gmail.com
2. צור גיליון חדש → שם: **זמין24 - לידים**
3. בשורה הראשונה, כתוב את הכותרות (עמודה בכל תא):
   `תאריך` | `שם` | `טלפון` | `סוג עסק` | `מקור` | `סטטוס` | `הערות`
4. שמור את ה-URL של הגיליון (נצטרך אותו) — משהו כמו:
   `https://docs.google.com/spreadsheets/d/XXXXXXXXX/edit`
5. שים לב ל-ID באמצע ה-URL (החלק בין `/d/` ל-`/edit`) — זה מזהה הגיליון

---

## משימה 2: יצירת Service Account (10 דקות)

זה "משתמש רובוט" שמאפשר לפונקציה לכתוב לגיליון בשמך.

1. היכנס ל-https://console.cloud.google.com/iam-admin/serviceaccounts?project=zamin24
2. לחץ **Create Service Account** (למעלה)
3. שם: `sheets-writer` → **Create and Continue**
4. בשלב ההרשאות (Role) — אפשר לדלג, לחץ **Continue** ואז **Done**
5. עכשיו החשבון מופיע ברשימה. לחץ עליו → לשונית **Keys**
6. **Add Key → Create new key → JSON → Create**
7. יורד קובץ JSON למחשב — **שמור אותו טוב, זו המפתח!** (לא לשתף, לא להעלות לגיטהאב)

---

## משימה 3: שיתוף הגיליון עם ה-Service Account (2 דקות)

1. פתח את קובץ ה-JSON שהורדת בעורך טקסט
2. חפש את השורה `"client_email"` — יש שם כתובת כמו:
   `sheets-writer@zamin24.iam.gserviceaccount.com`
3. העתק את הכתובת הזאת
4. חזור לגיליון בגוגל-שיטס → לחץ **Share / שיתוף** (כפתור כחול למעלה)
5. הדבק את הכתובת של ה-Service Account → תן הרשאת **Editor / עריכה** → שלח
   (זה מה שנותן לרובוט רשות לכתוב לגיליון)

---

## מה יהיה מוכן לפגישה הבאה

כשתסיים את 3 המשימות, יהיו לך:
- ✅ גיליון עם כותרות
- ✅ מזהה הגיליון (מה-URL)
- ✅ קובץ JSON של ה-Service Account
- ✅ הגיליון משותף עם ה-Service Account

ואז בפגישה אני:
1. אבנה פונקציית `addLead` שכותבת לגיליון
2. אעדכן את הבוט שיכתוב לשם כל ליד
3. אחבר את טופס נטליפיי (דרך HTTP POST) שיכתוב לשם גם כן
4. נבדוק שפנייה מהאתר ופנייה מהבוט שתיהן מופיעות בגיליון

## הערה חשובה על אבטחה
- קובץ ה-JSON = מפתח גישה. שמור אותו במקום בטוח, אל תעלה לשום מקום ציבורי.
- בפגישה נזין את תוכנו כ-secret ב-Firebase (כמו שעשינו עם הטוקן), לא בקוד גלוי.

## תזכורת — מה כבר עובד בינתיים
פניות מטופס האתר כבר נאספות ב: נטליפיי → האתר → לשונית **Forms**.
אז עד שנחבר את ה-Sheet, אתה לא מפספס אף ליד מהאתר.
