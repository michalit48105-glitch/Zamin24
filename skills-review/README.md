## הערות שכבר ידועות

- **Chief of Staff** הוא קובץ הגדרה של סוכן, לא סקיל. שמורות שתי הגרסאות: הגרסה של Claude Code (`chief-of-staff.md`) והגרסה של Kiro. הוא צריך חיבור למייל וליומן כדי לעבוד.
- **Last 30 Days** כולל סקריפטים (תיקיית `scripts`). חלק מהמקורות שלו דורשים התחברות או מפתח API, שעשוי להיות בתשלום.
- במאגר של Matt Pocock יש גם `skills/in-progress/chief-of-staff`. זה סקיל אחר מזה שבמדריך, ולא נשמר כאן.

## מה בודקים בכל סקיל לפני התקנה

לפי ההנחיות במדריך:

1. מה הוא עושה ולמי הוא מתאים.
2. לאילו קבצים, חשבונות והרשאות הוא זקוק.
3. האם הוא מריץ פקודות, שולח מידע החוצה, משנה או מוחק מידע, או דורש שירות בתשלום.
4. דברים חשודים, ומה לא הצלחנו לבדוק.

התקנה = העתקה לתיקייה `.claude/skills/<שם>/` (או `.claude/agents/` לסוכן), רק אחרי בדיקה ואישור.

## דוגמאות שימוש מהמדריך

**Chief of Staff**
```
השתמש ב־Chief of Staff והכן לי סיכום בוקר בעברית מהערוצים שחיברתי:
מה דורש תשובה, אילו פגישות יש היום ואילו משימות ממתינות לי.
הכן טיוטת תשובה לכל הודעה חשובה.
הצג הכול לבדיקה שלי, בלי לשלוח, להעביר לארכיון או לשנות את היומן.
```

**Anatomy** (`/anatomy`)
```
תסביר לי איך עובד מנוע של מכונית באמצעות המחשה אינטראקטיבית.
אפשר לי להזיז את הבוכנה ולראות איך התנועה הופכת לסיבוב.
כתוב את ההסברים בעברית פשוטה ופתח לי את התוצאה בדפדפן.
```

**Teach** (`/teach`)
```
אני מנהל עסק ורוצה ללמוד לקרוא דוחות שיווק בלי ידע קודם.
שאל אותי מה אני כבר יודע ומה אני רוצה לדעת לעשות.
בנה לי שיעור ראשון קצר בעברית עם דוגמה ותרגיל.
שמור את ההתקדמות כדי שנמשיך מאותה נקודה בפעם הבאה.
```

**Marketing Psychology** (`/marketing-psychology`)
```
אני מוכר [המוצר או השירות] ל[קהל היעד].
זו ההצעה שלי: [מדביקים את ההצעה].
בחר שלושה עקרונות פסיכולוגיים שמתאימים להצעה והצע ניסוח ברור ומשכנע יותר למודעה.
הסבר במשפט למה כל שינוי עשוי לעזור. אל תמציא המלצות, מספרים או מחסור.
```

**Last 30 Days** (`/last30days`)
```
חקור מה בעלי עסקים אומרים ב־30 הימים האחרונים על כלי AI לניהול סושיאל.
סכם בעברית: בעיות שחוזרות, כלים שמוזכרים ומה אנשים אוהבים או לא אוהבים.
צרף קישורים ותאריכי פרסום, וציין אילו מקורות הצלחת לבדוק.
בסוף הצע חמישה רעיונות לתוכן שמתבססים על הממצאים.
```
